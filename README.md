# مجمع هائل

مشروع تأسيسي لمنصة تعليمية عربية بتصميم كحلي وذهبي.

## بنية المشروع
- `public/`: ملفات الموقع الثابتة.
- `functions/`: Cloudflare Pages Functions للمصادقة وواجهة الذكاء الاصطناعي.
- `functions/_middleware.js`: يتحقق من جلسة دخول المنصة لطلبات API.
- `functions/api/`: واجهات تسجيل الدخول والمساعد الذكي.

## النشر على Cloudflare Pages عبر GitHub
1. ارفع محتويات هذا المجلد إلى جذر مستودع GitHub (لا ترفع ملف ZIP نفسه).
2. في Cloudflare Pages اختر **Connect to Git** ثم المستودع `Mujamma-Hail`.
3. اترك Build command فارغاً، واجعل Build output directory هو `public`.
4. بعد إنشاء المشروع، افتح Settings > Variables and Secrets وأضف الأسرار التالية في Production وكذلك Preview عند الحاجة:
   - `SITE_PASSWORD`: رمز دخول الزوار.
   - `DEVELOPER_PASSWORD`: كلمة مرور مستقلة لقسم المطور.
   - `SESSION_SECRET`: سلسلة عشوائية طويلة وفريدة (32 حرفاً أو أكثر).
   - `OPENAI_API_KEY`: اختياري لتشغيل المعلم الذكي، ويُضاف كـ Secret ولا يوضع في ملفات الموقع.
   - `OPENAI_MODEL`: اختياري، الافتراضي `gpt-4.1-mini`.
5. أعد النشر بعد ضبط الأسرار.

## تنبيهات مهمة
- لا تضع كلمات المرور أو مفاتيح API داخل GitHub أو داخل ملفات HTML.
- Direct Upload من لوحة Cloudflare لا يشغّل Pages Functions؛ استخدم Git integration أو Wrangler.
- قسم المطور محمي بجلسة موقّعة على الخادم. لا تشارك كلمة المرور مع أحد.
- هذه نسخة تأسيسية وليست منصة مكتملة المحتوى: ملفات المناهج الرسمية، قاعدة البيانات، مزامنة الملاحظات بين الأجهزة، رفع الصور وتحليلها، وأدوات الإدارة المتقدمة تحتاج إعداداً وتطويراً إضافياً.
- دفتر الملاحظات في هذه النسخة يحفظ على الجهاز والمتصفح فقط.
